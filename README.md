# Hotel-Webpage---Summer-Training
Summer training project — a full-stack frontend luxury hotel website built with HTML, CSS &amp; JavaScript. Features include user authentication, room booking with dynamic pricing, booking confirmation, fine dining &amp; boutique pages, admin panel, and localStorage-based data persistence.

# Hotel Website

A multi-page luxury hotel website built during my summer training program.

## What I Learned
- Structuring multi-page websites with HTML5
- Responsive design using CSS3 (Flexbox, Grid, Media Queries)
- JavaScript DOM manipulation and event handling
- Client-side user authentication using localStorage
- Dynamic data storage and retrieval (bookings, user accounts)
- Form validation and real-time feedback

## Features
-  Room browsing & booking form with dynamic price calculation
-  Booking confirmation page with unique confirmation number
-  User Sign Up & Login with localStorage authentication
-  Fine dining restaurant showcase page
-  Luxury watch boutique page
-  Admin panel
-  Fully responsive across mobile, tablet & desktop

## Pages
| Page | Description |
|------|-------------|
| index.html | Homepage with hero, about, rooms & dining preview |
| rooms.html | Booking form with date picker & pricing |

| dining.html | Restaurant showcase |

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · localStorage · Flatpickr.js · Google Fonts
